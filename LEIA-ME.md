# Refúgio da Família Koch — versão com Guia do Visitante

## Arquivos
- `index.html`: página inicial, as duas casas, informações resumidas, reservas e redes sociais.
- `guia.html`: Guia do Visitante com informações detalhadas e perguntas frequentes.
- `historia.html`: história e linha do tempo, com a fotografia aérea DJI_0042.jpg desfocada ao fundo.
- `assets/`: fotografias originais e recursos.

## Publicar no GitHub Pages
Extraia o ZIP, copie os arquivos e a pasta `assets` para a raiz do repositório, sem apagar a pasta `.git`. Faça commit e push pelo GitHub Desktop. Todos os links usam caminhos relativos e funcionam no GitHub Pages.

**Atenção:** o Guia do Visitante é uma página pública. Não coloque senhas, códigos de acesso ou dados privados nela. Informações que dependem da reserva devem ser confirmadas diretamente com a equipe.

Atualização: aba Redes Sociais aponta para a seção de Instagram e Facebook; nova aba Contato aponta para os cartões de e-mail, ligação/cópia do telefone e WhatsApp.
